# Which Claude model, and when

## Default: Sonnet 5, high effort, for everything

This is on the $20/month Pro plan. Sonnet 5 at high reasoning effort is the default for every task, no exceptions to reach for a different model just because a task looks hard or important.

## Opus 5: only when design is the actual goal

The one trigger to switch is taking a design seriously, specifically when working through Claude Design. That's the only case, not "this task feels important" in general, the trigger is design work specifically, not task difficulty.

## Fable 5: not used

No task so far has needed it. For someone new to using AI, unlikely they'd need it either, Sonnet 5 and Opus 5 cover what a normal workflow touches.

## Not covered

Haiku 4.5 isn't part of this criteria yet, no stated judgment for when it'd apply. If that case comes up, it's a sign to extend this domain, not to guess.

## Summary for the router

- Default task → Sonnet 5, high effort.
- Design work through Claude Design → Opus 5.
- Fable 5 → not needed so far, including for someone new to AI.
- Haiku 4.5 → not covered, ask instead of assuming.
